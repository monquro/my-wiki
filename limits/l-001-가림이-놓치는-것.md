# l-001 · 가림이 놓치는 것

- 본 날: 2026-11-03 (화)
- 대상: classifier/mask.js
- 관련: [[d-002-보내기-전에-가린다]]

## 무엇을 놓치나

«김민수씨 연락 주세요»의 **«김민수씨»는 가려지지 않는다.**

## 왜 놓치나

- mask.js 의 이름 규칙은 두 가지뿐이다.
  - 성씨로 시작하는 세 글자 뒤에 «입니다·고객·드림·님»이 올 때
  - «명의자» 바로 뒤에 올 때
- «씨»는 이 목록에 없다.
- README «주의»에도 «이름 뒤에 «입니다·고객·드림·님»이 없으면 놓칩니다»라고 적혀 있다.

## 확인

2026-11-06, mask.js로 직접 돌려 봤다.

| 넣은 문장 | 가린 결과 |
|---|---|
| 김민수씨 연락 주세요 | 김민수씨 연락 주세요 — 가리지 못함 |
| 김민수님 연락 주세요 | [이름]님 연락 주세요 |

## 아직 모르는 것

- 이름 말고 다른 개인정보가 얼마나 빠지는지(놓친 비율) — 미확인
