# d-004 · 열쇠는 코드 밖에

- 정한 날: 2026-11-05 (목)
- 대상: 고객 한마디 분류기 (classifier/)

## 무엇을 정했나

- Gemini 열쇠(GEMINI_API_KEY)는 **Vercel 설정(환경 변수)에만** 둔다.
- 폴더에는 **잠금(deny)**과 **검문(훅)**을 건다.

## 왜

파일에 적힌 이유:

- api/classify.py 머리말: «이 앱에서 서버가 필요한 유일한 자리다. 키를 숨기기 위해서 존재한다. 키를 app.js 에 적으면 브라우저 개발자 도구에서 그대로 보인다.»
- README «주의»: «키를 저장소에 커밋하지 마십시오. 한 번 올라가면 지워도 기록에 남습니다.»

잠금과 검문을 둘 다 건 이유(하나만 걸지 않은 이유)는 **미확인**이다.

## 버린 것

| 방법 | 버린 이유 |
|---|---|
| 열쇠를 app.js 에 적는다 | 브라우저 개발자 도구에서 그대로 보인다 (api/classify.py) |
| 열쇠를 저장소에 넣는다 | 한 번 올라가면 지워도 기록에 남는다 (README) |
| 그 밖에 검토한 방법 | 미확인 |

## 근거

| 무엇 | 어디 |
|---|---|
| 열쇠는 환경 변수에서만 읽는다 | classifier/api/classify.py — `os.environ.get("GEMINI_API_KEY")` |
| Vercel에 넣는 법 | classifier/README.md «올리기» |
| 잠금: `Read(./.env)` · `Read(./.env.*)` deny | classifier/.claude/settings.json — 저장 지점 `54dab51` (2026-11-05 목) |
| 검문: git add · commit · push 직전에 열쇠 모양을 찾아 막는 훅 | classifier/.claude/hooks/block_secrets.py. 파일은 `25f337c`(화)에 들어왔고, settings.json 에 건 것은 `54dab51`(목) |
| .env 는 저장소에 넣지 않는다 | classifier/.gitignore |

## 아직 모르는 것

- 폴더에는 .env 파일이 있다. 위키 규칙에 따라 읽지 않았다. 그 안에 열쇠가 들어 있는지는 미확인.
- «Vercel 설정에만»은 결정이다. 실제로 열쇠가 다른 곳에 없는지는 확인하지 않았다.
